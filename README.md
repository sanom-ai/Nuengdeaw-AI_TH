# Nuengdeaw AI

Nuengdeaw AI is an emotional intelligence product ecosystem that now includes both a presentation-grade landing layer and the real source code for Gen1-Gen4 product experiences.

## Repository Structure

- `landing/` - standalone showcase and project-entry experience
- `products/gen1/` - BioSignal product page
- `products/gen2/` - NeuroSignal product page
- `products/gen3/` - Wellness product page
- `products/gen4/` - LLM Hub product page
- `products/shared/` - shared runtime, AI modules, and foundation data
- `assets/images/` - shared landing visuals
- `docs/` - architecture and system documentation
- `scripts/` - project utility scripts

## Included Source

This repository now includes:

- landing showcase experience
- Gen1 through Gen4 product HTML entry pages
- shared JavaScript runtime and AI modules
- foundation JSON files used by the products
- architecture documentation and utility scripts
- package metadata for local project scripts

## Notes

The landing experience is separated from the product implementation so the repository can serve both presentation and source-code use cases more cleanly.
